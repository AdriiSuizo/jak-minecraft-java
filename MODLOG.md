# Jak Worlds — Minecraft Java

2026-11-03: Full Jak port authorized. Target actual Minecraft Java 26.3, Fabric 0.20.1, Java 25. Separate project and dev gameDir; no changes to Minecraft personal saves or the Rust runtime.

Scope: Jak/Daxter, movement, combat and guns, eco/powers, JET-Board, fauna/enemies/citizens, mounts, zoomers/HellCat, Jak 3 wheeled vehicles, cities/tower/interiors/props, animation/particles/audio, persistence and controller inputs. Excludes MW2 and Skate 3. JET-Board is included.

Workflow learned by read-only inspection of LSC4 and GTA SA: source oracle and function provenance; isolated logic/host/presentation; exact build/config/asset fingerprints; native scenario evidence; preserve rejected findings; reuse unchanged evidence. No commands that mutate/build those projects. No copied GTA addresses, code, instructions or assets.

Implementation: Fabric owns Minecraft registries, world, collision, entity lifecycle, damage, inventory and saves. Existing pure Rust Jak core (glam only) copied under native/jak-core with source hashes; JNI batched bridge avoids pulling in Bevy, IW4, MW2 or Skate. Rendering uses Minecraft APIs. Existing Minecraft GUI, crafting, trades and terrain remain the actual game implementation.

Current work: create and build Fabric host, connect native core and asset pipeline, then integrate all feature groups against the scope ledger. A compiling scaffold is not completion of the port.

Native import checks: 82 existing core tests pass; real JNI boundary floor/jump/truncated-packet/stale-handle check passes. Owned original art groups load 255 authored animation timings and align tracks.
First native client exposed two real importer errors before acceptance: Daxter morph channels require weight animation (implemented); art-group GLBs share vertex accessors across models, so unused vertices from a different skeleton must not be skinned (primitive compaction implemented with indexed-joint validation). Initial attempts preserved in client-first.log/client-morph.log; neither is accepted gameplay evidence. Java-owned movement packets also needed server ownership routing; added targeted server movement mixin.
